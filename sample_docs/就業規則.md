# 就業規則（株式会社サンプル商事）

第1条（目的）
この規則は、株式会社サンプル商事（以下「会社」という）の従業員の労働条件、服務規律その他の就業に関する事項を定めるものである。

第2条（適用範囲）
この規則は、会社に雇用されるすべての正社員に適用する。パートタイム従業員および契約社員については、個別の雇用契約および別に定める規程による。

第3条（労働時間）
所定労働時間は、1日8時間、週40時間とする。始業時刻は午前9時、終業時刻は午後6時とし、休憩時間は正午から午後1時までの1時間とする。

第4条（休日）
会社の休日は次のとおりとする。
1. 土曜日および日曜日
2. 国民の祝日
3. 年末年始（12月29日から1月3日まで）
4. 夏季休暇（8月13日から8月15日まで）

第5条（時間外労働・残業）
業務の都合により時間外労働（残業）を行う場合は、事前に所属長に申請し、承認を得なければならない。時間外労働の申請は勤怠システムから行うこと。承認のない時間外労働は原則として認めない。

第6条（年次有給休暇）
入社後6か月間継続勤務し、所定労働日の8割以上出勤した従業員には、10日の年次有給休暇を付与する。以後、勤続年数に応じて法定どおり付与する。
2. 年次有給休暇を取得する場合は、原則として3営業日前までに勤怠システムから申請しなければならない。
3. やむを得ない事由により当日取得する場合は、始業時刻までに所属長へ電話またはチャットで連絡すること。

第7条（特別休暇・慶弔休暇）
従業員は次の場合に特別休暇（慶弔休暇）を取得できる。
1. 本人が結婚するとき：5日
2. 子が結婚するとき：2日
3. 配偶者、子または父母が死亡したとき：5日
4. 祖父母、兄弟姉妹が死亡したとき：2日
5. 配偶者が出産するとき：3日

第8条（賃金の計算期間および支払日）
賃金（給与）は毎月末日締めとし、翌月25日に従業員が指定する銀行口座へ振り込む。支払日が休日の場合は、その前営業日に支払う。

第9条（賞与）
賞与（ボーナス）は、会社の業績および本人の勤務成績を考慮して、原則として毎年6月および12月に支給する。

第10条（退職）
自己都合により退職する場合は、退職希望日の30日前までに所属長へ退職届を提出しなければならない。

第11条（リモートワーク・在宅勤務）
従業員は、所属長の承認を得て週2日までリモートワーク（在宅勤務）を行うことができる。リモートワークを行う場合は、前日までに勤怠システムから申請すること。ただし、入社後3か月間は原則として出社とする。

第12条（副業・兼業）
従業員が副業・兼業を行う場合は、事前に会社所定の届出書を人事部に提出し、許可を得なければならない。会社の業務と競業する業務、および会社の信用を損なうおそれのある業務は認めない。

第13条（秘密保持）
従業員は、在職中および退職後においても、会社の営業上・技術上の機密情報および顧客情報を第三者に開示または漏えいしてはならない。

第14条（服務規律）
従業員は、会社の指示命令を守り、誠実に職務を遂行しなければならない。ハラスメント行為、職場秩序を乱す行為は懲戒の対象とする。
