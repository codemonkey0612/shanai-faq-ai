# 経費精算規程（株式会社サンプル商事）

第1条（目的）
この規程は、株式会社サンプル商事の業務遂行に伴い従業員が立て替えた経費の精算に関する事項を定める。

第2条（経費の範囲）
精算の対象となる経費は、次のとおりとする。
1. 交通費（電車、バス、タクシー等）
2. 出張旅費（宿泊費、日当を含む）
3. 交際費（取引先との会食、贈答品等）
4. 会議費
5. 消耗品費・書籍代

第3条（申請期限）
経費の精算は、経費が発生した月の翌月5日までに経費精算システムから申請しなければならない。期限を過ぎた申請は、原則として精算できない。

第4条（領収書）
経費精算には領収書（レシート）の添付を必須とする。金額が3万円以上の場合は、宛名（株式会社サンプル商事）入りの領収書が必要である。電子レシート・スクリーンショットも認める。

第5条（交通費）
交通費は、最も経済的な経路（最安経路）で計算する。タクシーの利用は、深夜（22時以降）の帰宅、重い荷物の運搬など、合理的な理由がある場合に限り認める。

第6条（出張旅費）
日帰り出張の日当は2,000円、宿泊を伴う出張の日当は1泊につき3,000円とする。宿泊費の上限は1泊12,000円（東京・大阪は15,000円）とする。新幹線は普通車指定席を利用すること。

第7条（交際費）
取引先との会食等の交際費は、1人あたり5,000円を超える場合、事前に部門長の承認を得なければならない。参加者の氏名・会社名を申請時に記載すること。

第8条（精算金の支払い）
承認された経費は、申請月の末日に給与振込口座へ振り込む。
